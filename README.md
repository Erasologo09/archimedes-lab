# ЛАБА: Закон Архимеда

Интерактивная научная веб-лаборатория по закону Архимеда и гидростатике. Разработана в концепции яркого минимализма с физическими анимациями на пружинах, живыми гидростатическими расчётами и контекстным физическим тьютором.

## 🔬 Интерактивные лаборатории

1. **Гидростатический бассейн (`#simulator`)**
   - Интерактивное погружение тела в жидкость (перетаскивание курсором или ползунками).
   - Динамические векторные стрелки силы Архимеда $F_А$ и силы тяжести $mg$.
   - Расчёт гидростатического давления $P_{верх}$, $P_{низ}$ и перепада $\Delta P$, порождающего силу Архимеда.
   - Свободное физическое равновесие плавания или принудительное удержание.
   - 6 типов жидкостей (от спирта и масла до морской воды и ртути) и 8 материалов.

2. **«Эврика!»: Загадка царской короны (`#crown-lab`)**
   - Историческая реконструкция задачи царя Гиерона Сиракузского (1000 г).
   - Два прибора Архимеда:
     - **Переливной сосуд**: вытеснение воды в мерную мензурку капля за каплей.
     - **Гидростатические весы**: пружинный наклон коромысла при погружении в воду из-за разницы плотностей золота и серебра.
   - Плавная регулировка пробы сплава от 40% до 100% золота с физическим вердиктом.

3. **Судостроение и ватерлиния (`#ship-lab`)**
   - Разрешение парадокса «сталь тонет, а корабль плывёт».
   - Переключение между сплошным стальным бруском (7800 кг/м³) и полым корпусом судна.
   - Погрузка контейнеров, динамическое изменение осадки в метрах и запаса плавучести.
   - Международная грузовая марка Плимсоля и тест в пресной, морской и гиперсолёной воде.

4. **Физический помощник (`#assistant`)**
   - Считывает показатели всех опытов в реальном времени и объясняет происходящее с точки зрения фундаментальных законов физики.

5. **Звуковое оформление**
   - Мягкий синтез физических звуков на Web Audio API (всплеск воды, перезвон гидростатических весов, тактильные щелчки тумблеров) с кнопкой включения/выключения.

## 🚀 Запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Проверка типов
npm run lint

# Сборка продакшн-бандла
npm run build
```
